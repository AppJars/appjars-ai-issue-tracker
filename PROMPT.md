You are working on a Spring Boot + Vaadin application generated by Craft, with three AppJars
already integrated: Issue Tracker, User Manager and Activity Log.

1. Read `AGENTS.md` and every file in `specs/`, starting with `specs/00-principles.md`.
2. Use the `appjars-docs` MCP server to look up how the AppJars work (services, views, routes,
   free-mode limits) before writing code that depends on them.
3. Implement specs 01, 02 and 03, in that order.
4. After each spec, run `mvn -q -DskipTests package`. When all three are done, start the app with
   `mvn spring-boot:run`, check the log for errors and fix them, then stop it.
5. Update `specs/STATUS.md`: mark each spec done or partial, and list anything you dropped under
   "Not done".

Keep it simple. If something gets complicated, drop it and write it down instead of fighting it.
