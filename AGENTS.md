# Issue Tracker — notes for coding agents

Generated by Craft (https://craft.appjars.com). Spring Boot 4.1.1, Vaadin
25.2.9, Java 21, Maven. Run with `mvn spring-boot:run`; production build
with `mvn clean package -Pproduction`.

## Layout

- `com.example.issuetracker.Application` — entry point. Holds `@EnableVaadin`, `@ComponentScan` and the
  theme `@StyleSheet`s. Every annotation is commented; do not "clean up" entries that look redundant.
- `com.example.issuetracker.views.MainLayout` — the shell (`@Layout`). Navigation is a `SideNav` listing
  every view of every AppJar, each entry guarded by an access check. Remove entries you do not need;
  the routes stay registered.
- `com.example.issuetracker.views.HomeView` — placeholder start page. Replace it.
- `com.example.issuetracker.views.LoginView` — extends the login view provided by User Manager.
- `com.example.issuetracker.security.SecurityConfiguration` — `SecurityFilterChain` using Vaadin 25's
  `VaadinSecurityConfigurer`. Public matchers go before `http.with(vaadin(), ...)`.
- `com.example.issuetracker.config.UserManagerConfig` — points the module's `RouteConfigurer` at `MainLayout`.
- `com.example.issuetracker.config.ActivityLogConfig` — points the module's `RouteConfigurer` at `MainLayout`.
- `com.example.issuetracker.config.IssueTrackerConfig` — points the module's `RouteConfigurer` at `MainLayout`.
- `com.example.issuetracker.config.IssueTrackerLoggedInUser` — tells Issue Tracker who is signed in (required bean; the application does not start without it).
- `src/main/resources/application.properties` — database, Vaadin and per-module settings.
- `src/main/resources/META-INF/resources/styles.css` — theme customisation (plain CSS variables).

## Rules that are easy to break

- Vaadin 25 has no `@Theme`, no `theme.json`, no `frontend/themes/`. Styles are plain CSS.
- `@EnableVaadin` must include `com.example.issuetracker` or the theme silently falls back to Aura.
- `MainLayout` must keep an access annotation (`@PermitAll`/`@AnonymousAllowed`).
- `vaadin.allowed-packages` must keep `com.appjars` and `com.flowingcode`.
- Maven only. Do not add Gradle or a wrapper.
